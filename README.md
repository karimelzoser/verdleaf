# Verdleaf Global — Digital Export Experience

A bespoke, cinematic, SEO-first B2B agricultural ingredients website for Verdleaf Global, Egypt.

**Creative concept: From Egyptian soil to the world.**

The site is a digital visit to the company, not a template or retail shop. Its commercial objective is qualified international buyer enquiries, backed by verified product information, certifications and real operational photography.

## Architecture decision (proposed)
Laravel/PHP + MySQL, server-rendered Blade templates, Vite-built CSS and selective JavaScript/React islands; admin CMS, RFQ basket and integrations. Hosting compatibility must be verified against the client's exact Hostinger subscription before selecting runtime versions or deployment layout.

## Project rules
- No templates, fabricated testimonials, invented certificates, export destinations, harvest dates, capacity, or technical specifications.
- Use approved original company media. Illustrative visuals must remain clearly marked on staging and cannot imply ownership or actual operations.
- English-first, native Arabic RTL content, human editorial review.
- Motion is an enhancement, never a navigation dependency; respect reduced motion and keyboard access.
- Keep public pages crawlable, responsive, fast, and accessible.
- Do not publish or deploy to the live domain without approval. No credentials or customer records in this public repository.

## Status
Planning initialization. Application implementation, hosting verification and client data approval are separate milestones. No production website is deployed by this commit.
