## Data and blockers
The original public website was rechecked: https://verdleaf.com/, https://verdleaf.com/products/, https://verdleaf.com/about-us/, https://verdleaf.com/contact-us/. Original catalogue names and published company contact/heritage claims are in a source register. Existing certificate marks are not verified certificates; area units conflict. Public WordPress media and page API retrieval failed, so no actual company photography was imported. All illustrative artwork is original and clearly marked. No invented dates, capacity, laboratory results, events, visits or export stock. Obtain original WordPress export and media, logo, current certificates, crop data, technical specs, client approval and hosting access.
## Local install
PHP 8.2+, Composer 2, required Laravel extensions, MySQL/MariaDB. composer install; copy .env.example to .env, configure DB; php artisan key:generate; php artisan migrate --seed; php artisan verdleaf:admin EMAIL; php artisan serve. Keep VERDLEAF_PREVIEW=true. Optional expansion candidates: php artisan db:seed --class=ExpansionCandidateSeeder (creates drafts only, do not run as production catalogue without review). Run vendor/bin/phpunit. Browser: npm install; npx playwright install chromium; npm run test:browser on a seeded local preview. Node is test-only. See HOSTINGER-DEPLOYMENT.md and RELEASE-CHECKLIST.md. Do not deploy to live domain without approval.
